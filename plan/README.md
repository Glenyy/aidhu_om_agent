本目录保存首版项目的软件开发生命周期规划。本轮交付为规划文档和流程图；程序、运行环境、模型调用及准确率验收均属于后续开发阶段，尚未完成。

## 2. 已确认的决定

| 项目 | 本版决定 |
| --- | --- |
| 项目位置 | 独立项目 aidhu_om_agent；当前生命周期规划保留在 plan |
| 目录标准 | 参考用户提供的 Claude Code 项目结构；根目录依赖、src 源码、tests 测试、docs 文档 |
| 运行形态 | 个人电脑本地运行，通过浏览器访问；通常百条，首版面向约 1000 条以内 |
| 页面范围 | 上传 Excel、查看进度与结果、下载文件；人工复核在导出 Excel 中填写 |
| 问题范围 | 仅意图明确的问题，不增加意图识别流程 |
| 输入 | 编号、q、a、ref1—ref10；无人工标签；ref 单元格允许为空 |
| 评估依据 | 根据问题重新检索的这组资料，不重新检索或联网补充 |
| 判别流程 | 两阶段，正常记录两次模型调用 |
| 技术路线 | 普通 Python 固定流程、SDK、Pydantic、SQLite；此决定替代早期 LangGraph 建议 |
| 模型分工 | 默认 V3 → R1，两阶段分别可配置 |
| 错误标准 | 关键遗漏算错，非必要背景和措辞差异不算错 |
| 不确定资料 | 暂判“未检索到正确资料”并标记人工复核 |
| 日常复核 | 只复核被标记记录；导出清单，首版不回读复核结果 |
| 质量重点 | 降低非正确类被误判为“回答正确”的比例 |
| 质量目标 | 上述比例 ≤5%，Macro-F1 ≥0.80；验收集分类完成率 100% |
| 验收数据 | 现有样例经人工核定；约 20 条校准，其余作为保留验收集 |

建议技术组合为 Vue 3 + TypeScript + Vite + Element Plus 前端、Python 3.12 + FastAPI 后端、独立串行 worker 和本地 SQLite。目录、API、数据库及状态设计均已提交工程方案，仍待审阅；上表中的本地运行和页面范围已根据用户回复确认。

本版细化普通恢复与显式重试、全部结果保存后的收尾恢复、独立导出状态。初始上传/行数保护值是待审阅建议，实际服务限制在开发兼容验证时确定；不裁剪资料。

首版不增加网页人工标注、复核回读、多人账号或在线部署。命令行入口作为辅助工具，与网页共用批次服务和唯一 worker。

## 3. 阶段与职责

当前处于 M0：规划交付与审阅。M1—M6 尚未开展；具体完成条件见开发任务文档。用户已决定页面交互、模型结构及提示词进一步细节到实际开发时再按情况完善；当前不继续扩写这些专项规划。

- 用户负责需求口径、人工核定标准、规划审阅和业务验收。
- 开发者负责实现、工程测试、模型兼容性验证和结果报告。
- 模型输出是待验证的预测；不能用模型预测自动建立人工验收标准。

开发以本套规划整体审阅通过为前置条件。审阅修改会反映到对应文档和版本记录。
