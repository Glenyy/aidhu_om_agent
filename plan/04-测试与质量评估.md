# 04 测试与质量评估

规划版本：v2.3｜日期：2026-10-05｜状态：待用户审阅

工程测试回答“程序是否正确执行流程”，分类评估回答“模型是否按人工口径判对”。二者分别报告，模拟客户端通过不代表实际模型准确率通过。

## 1. 验收数据准备

来源为用户已有的 100 条样例。原“判断”仅是可修订参考，不直接作为核定标准。日常输入仍只有编号、q、a、ref1—ref10，运行无需人工标签。

人工核定文件按编号保存“人工判断、人工理由”，必要时附关键 ref。人工先核对问题范围和证据，再确认三个标签之一；不能把 agent 预测自动复制为标准。

不符合意图明确范围的记录在人工准备阶段排除，保留编号和排除理由。分类程序不检测意图。

核定后冻结原始数据版本及摘要、人工标签版本/核定人/日期、校准与验收划分清单，以及排除记录和理由。

## 2. 分层划分与使用规则

校准集约 20 条，保留验收集为其余符合范围的记录，随机种子固定为 20261005。

按人工核定的三类比例分配校准数量，采用最大余数分配，确保每类至少 1 条校准样本、至少 5 条验收样本。边界测试可以另加合成案例，不从验收集临时挑题调试。无法同时满足数量和类别要求时，先补数据。

划分后：

1. 仅用校准集及独立合成案例调整规则和提示词。
2. 冻结规则、提示词、结构和模型配置。
3. 在保留集上执行正式评估，保存全部原预测。
4. 若分析验收错误后继续调参，该集合转为回归数据。
5. 新质量验收补充未用于调试的数据；同一集合上的重复改善仅报告为回归结果。

人工核定本身可以阅读所有原始记录；禁止的是以保留集模型结果反复调整后再声称独立验收。

## 4. 工程测试场景

| 编号 | 场景 | 必须验证的行为 |
| --- | --- | --- |
| E-01 | 必要列缺失、编号重复 | 模型调用前阻止批次 |
| E-02 | 单条缺失 q/a/编号 | 失败行可追踪，其余有效行继续 |
| E-03 | 部分 ref 空值 | 不当作技术失败，保留十个位置 |
| E-04 | 检查实际构造的请求 | 阶段一不含 a，阶段二含全部原 ref |

## 5. 分类指标

固定类别顺序：回答正确、未检索到正确资料、检索到正确资料但回答错误。

混淆矩阵行是真实人工标签，列是 agent 预测。每类报告 TP、FP、FN、精确率、召回率和 F1；Macro-F1 是三个 F1 的算术平均。

~~~text
非正确类误判正确率
= 人工标签非“回答正确”且预测为“回答正确”的数量
  / 人工标签非“回答正确”的数量

总体一致率 = 预测与人工标签一致的数量 / 参与分类评分的数量
分类完成率 = 有合法分类的有效记录数 / 全部有效记录数
复核比例   = 需人工复核的已分类记录数 / 全部已分类记录数
~~~

需复核记录参与原预测评分，不剔除；人工修订不计作 agent 预测。每项指标同时报告计数和分母。

任一人工类别缺失，或保留集该类不足 5 条，不宣称三分类验收完成。分母为零的指标记为不可计算，不记为通过。

缺失预测和技术失败单独报告。可提供已分类子集的诊断指标，但有效记录未全部完成时，总体验收不得通过。

## 6. 通过条件与报告

必须同时满足：

- 非正确类误判正确率 ≤5%。
- Macro-F1 ≥0.80。
- 验收集有效记录分类完成率 100%。
- 每类验收样本至少 5 条，无编号遗漏/重复或非法标签。
- 工程关键场景全部通过。
- 复核清单、失败记录、版本和证据可追踪。

报告包含数据版本、核定过程、排除/划分清单、运行版本、原预测、总体/类别指标、混淆矩阵、复核率、失败率、阶段更正、调用尝试及耗时。

抽查阶段一漏读/误读和阶段二错误使用证据，分别记录，不把所有错误归为模型能力问题。

目前尚无人工核定的保留集评估结果。质量阈值是验收目标，小样本通过只能说明该批次结果，不证明大规模稳定效果。
