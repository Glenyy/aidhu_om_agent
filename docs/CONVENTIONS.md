# 开发约定

目录基线为 [v2.3 目录设计](../plan/07-项目目录与前后端选型.md)。前端依赖在根目录用 pnpm 管理，Python 包由根目录 pyproject.toml 管理。

实施拆分与状态见 [实施入口](implementation/README.md)。进入阶段前讨论具体小步骤并保存方案；用户批准覆盖的步骤后开发。阶段结束主动自动化审阅，通过后交付实际手动操作指南，用户接受单独记录。

全项目规则为 [阶段执行](../.claude/rules/development-workflow.md) 和 [审阅交付](../.claude/rules/review-and-handoff.md)，同时遵守对应路径规则。

当前源文件为占位。不得通过空函数、假标签或模拟准确率宣称完成。输入快照、agent 原预测、人工修订与技术失败分别保留。

后端凭据从环境变量读取；模板不含真实密钥。原业务 Excel、运行状态、结果和个人配置不提交。.gitkeep 只用于保留空目录。

页面、模型响应和正式提示词在所属阶段前讨论；相关具体实现及检查结果同步文档。依赖确定后由工具生成真实锁文件，不手写伪锁。
