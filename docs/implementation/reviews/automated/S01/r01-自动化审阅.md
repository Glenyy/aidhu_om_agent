## 3. 代码与合同核对

- **输入范围与三分类**：S01 未实现解析与判别，`excel/`、`agent/`、`schemas/` 仍为占位，未触碰业务合同。符合阶段边界。
- **凭据处理**：`config.py` 只在 `load_config()` 运行时从 `.env`/进程环境读取；`ModelConfig.api_key` 用 `field(repr=False)`，`AppConfig.snapshot()` 只输出 `api_key_present` 布尔值。实测 repr 与快照均不含密钥字符串（单测 `test_snapshot_never_contains_secret`、`test_repr_of_config_hides_secret`）。
- **脱敏**：`RedactingFilter` 在日志落地前调用 `redact()`，替换已登记凭据值及 `sk-` 令牌。实测日志文件中不含被记录的密钥与令牌（单测 `test_logging_redacts_secret`）。
- **.env 不污染进程环境**：`load_config` 用 `dotenv_values` 读入字典合并，不调用 `load_dotenv`，实测不写入 `os.environ`（单测 `test_dotenv_does_not_write_os_environ`）。
- **路径与工作目录无关**：路径由 `project_root()`（包文件位置推导）解析为绝对路径；在三个不同 cwd 下快照完全一致（单测 `test_paths_independent_of_cwd`）。
- **凭据回退**：阶段级变量优先，缺失时回退 `credentials.fallback_env`（默认 `AIDHU_API_KEY`）；两个阶段分别验证（单测 `test_stage_key_used_when_present`、`test_stage_key_falls_back_to_shared_key`）。
- **配置错误不泄露密钥**：`ConfigError` 只描述字段路径；单测断言错误信息含 `stage2.model` 且不含密钥值。
- **前端不接触模型**：前端仅加载 Vue/Router/Element Plus，无 API 调用与密钥引用，符合 [前端约定](../../../../../.claude/rules/frontend.md)。
- **包资源**：hatchling `packages` 已自动收进 `prompts/*.md` 与 `storage/schema.sql`，无需额外声明（wheel 内容实测确认）。
- **未实现项**：`llm/`、`excel/`、`storage/database.py`、`repositories/`、`services/`、`api/`、`worker.py` 仍为占位；`run/resume/export/evaluate` 命令未实现，执行时给出明确未实现提示与退出码 2。
