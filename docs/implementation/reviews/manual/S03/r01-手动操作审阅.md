## 1. 准备与启动

### 1.1 启动服务

打开 Anaconda Prompt：

```bat
conda activate aidhu_agent
cd /d D:\pyProjects\dha_projects\aidhu_om_agent
python -m aidhu_om_agent serve
```

应观察（逐字实跑输出）：

```
INFO:     Application startup complete.
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
界面地址：http://127.0.0.1:8000/（按 Ctrl+C 停止）
```

**保持这个窗口开着**，它是后端服务。（端口换用 8124 时，这两行的端口也随之为 8124。）

`python -V` 若不是 `Python 3.12.15`，把上面的 `python` 全部换成全路径解释器 `D:\anaconda\envs\aidhu_agent\python.exe`。

若 8000 端口被占用，改用：

```bat
python -m aidhu_om_agent serve --port 8124
```

后文所有 `http://127.0.0.1:8000/` 换成对应端口。

### 1.2 打开页面

浏览器访问 **http://127.0.0.1:8000/**（界面只有一个页面，路由为 `/`）。

页面由 `dist/frontend` 的构建产物提供。若页面打不开或提示 404，说明构建产物缺失，在**另一个**终端执行一次：

```bat
cd /d D:\pyProjects\dha_projects\aidhu_om_agent
pnpm install
pnpm build
```

然后刷新页面。构建产物不是验收对象，只是页面的来源。

### 1.3 关于费用与凭据

- **本指南全部步骤走模拟模式，不调用任何真实模型，零费用。** 第 14 步是唯一的真实模式步骤，标为**可选**且**需另行授权**。
- 模拟模式的响应由程序内确定性合成逻辑生成（`model` 显示为 `mock-deterministic`，结果区带 `simulated: true`），仅用于验证交互、流程与边界，**不能作为模型分类质量的证据**。
- 模拟响应里的说明文字多数带「（模拟）」前缀，表示这是合成情境文案，**不是对你这份数据的真实分析结论**。同一条记录（同一编号）在模拟模式下每次判都一样。情境由编号决定，所以换一份样例、换一个编号，看到的标签与复核标记就可能不同。
- 你不需要在本指南里输入任何密钥。真实模式的凭据已由开发者在本机 `configs/config.local.toml` 与 `.env` 配好，这两个文件都被 `.gitignore` 忽略，界面与日志都不会显示密钥内容。

### 1.4 会生成什么文件

- 样例文件：点「下载示例文件」后由**浏览器**下载到你本机默认下载目录（如 `C:\Users\<你>\Downloads\synthetic-five-scenarios.xlsx`）。仓库内不含任何二进制 Excel——样例是服务端现场用 openpyxl 合成的合成数据，不含真实业务资料。
- 服务端**不落库**：上传的文件、预检快照、判别任务都在内存里（S03 明确为临时实现）。**服务一停，这些全部消失**，重启后需要重新上传。

### 1.5 停服务

回到服务终端按 `Ctrl+C`。任务完成后请停掉服务，避免后台常驻。

### 1.6 本轮修复说明：状态行「当前阶段」

你在 2026-10-06 首次界面操作中发现：任务已完成时，状态行显示 `状态：completed｜当前阶段：等待中`，看起来像任务还没跑完。**这是界面文案缺陷，不影响任何数据**——后端在任务结束时会把「当前阶段」清空，而旧版页面把空值一律显示成「等待中」。

已按你的要求修复（[自动化审阅 §4 第 10 条](../../automated/S03/r01-自动化审阅.md)，同一交付轮次内处理，未另开 `r02`）：

- 终态（`completed` / `partial_failed` / `failed`）显示 **`当前阶段：无（任务已结束）`**；
- 「等待中」只在任务**尚未进入任何阶段**时出现。

**你这边只需要在浏览器里按一次 `Ctrl+F5` 强制刷新**——服务端静态文件按请求读盘，`dist/frontend` 重建后**不需要重启服务**（本轮用运行中的 uvicorn 实测：向 `dist/frontend/index.html` 追加内容后立即生效、撤回后立即消失；`data/runtime/server5.log`）。若刷新后仍是旧页面，再按 §1.1 重启服务。判定依据是页面加载的资源名变成 `assets/index-DMGrfYyI.js`（旧的是 `assets/index-DAwUnP0q.js`，可在 F12 → Network 里看到）。修复只改了显示文案，预检计数、标签、证据、更正与复核标记**全部不变**，A 组与 B 组的期望值除第 9 步新增的 `当前阶段` 一项外都与原表一致。

## 4. 结束、恢复与文件保存

- **停止**：回到服务终端按 `Ctrl+C`。没有需要优雅关闭的后台任务——判别是页面内同步等结果的单条任务。
- **恢复**：S03 **没有**断点续跑。上传、预检快照与任务都在内存里，**服务一重启就全部丢失**；恢复方式就是重新上传同一个文件、重新预检、重新判。这一限制属 S03 已声明的范围（持久化、批次列表、恢复、导出都在 S04/S05/S06）。
- **重复操作**：同一条记录可以重复判多次，每次生成新的 `job_id`，互不影响。模拟模式下同一份样例同一编号的结果**每次相同**（确定性合成）。样例文件可无限次重新下载。
- **建议保留**：下载到本机的 `synthetic-*.xlsx`、你的页面截图、以及本步骤表。仓库中不含样例二进制，服务端也不落库，无需清理仓库产物。
- **请勿删除** `src/aidhu_om_agent/excel/samples.py`——它是全部合成样例的唯一来源。
