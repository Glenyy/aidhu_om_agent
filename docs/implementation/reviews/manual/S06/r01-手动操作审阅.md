## 1. 准备与启动

### 1.1 启动界面服务（窗口 A）

打开 Anaconda Prompt：

```bat
conda activate aidhu_agent
cd /d D:\pyProjects\dha_projects\aidhu_om_agent
python -m aidhu_om_agent serve
```

应观察：

```
INFO:     Application startup complete.
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
界面地址：http://127.0.0.1:8000/（按 Ctrl+C 停止）
```

**保持窗口 A 开着**。若 8000 被占用，改用 `python -m aidhu_om_agent serve --port 8124`，后文端口随之替换。

`python -V` 若不是 `Python 3.12.15`，把上面的 `python` 换成 `D:\anaconda\envs\aidhu_agent\python.exe`。

### 1.2 启动队列消费者（窗口 B）

**再开一个** Anaconda Prompt：

```bat
conda activate aidhu_agent
cd /d D:\pyProjects\dha_projects\aidhu_om_agent
python -m aidhu_om_agent worker
```

应观察：

```
worker w-<12 位标识> 已启动（模式 mock）；数据库 <项目根>\data\state.sqlite3
按 Ctrl+C 停止；退出时保留未消费的 queued 任务。
```

- **默认就是模拟模式**（`--mode mock`），不调用真实模型、零费用。**不要**加 `--mode real`。
- 窗口 B 大多数时候是**安静**的，只在真的消费到任务时才有输出。
- 同一时刻**只允许一个 worker**；再开一个会立刻退出（退出码 3）。
- 本指南只在 A 组需要它工作；B 组以后都是**只读浏览**，窗口 B 可以继续开着。

### 1.3 打开页面并强制刷新

浏览器访问 **http://127.0.0.1:8000/** ，按一次 **`Ctrl+F5`**。

**本阶段前端有改动，必须强刷**。判定方法：按 `F12` → Network，页面加载的脚本名应为 **`assets/index-UZaMuiYy.js`**（S05 是 `index-A7CRyeKF.js`）；样式为 **`assets/index-BPd3CWgk.css`**。若名字对不上，说明浏览器用了缓存或 `dist/frontend` 不是本次产物——在**另一个**终端执行 `pnpm install` 后 `pnpm build` 再强刷（静态文件按请求读盘，重建后**不需要重启服务**）。

### 1.4 关于费用、凭据与数据位置

- **本指南全部步骤走模拟模式，不调用任何真实模型、零费用**，不含任何真实模式步骤。
- 页面与接口**从不显示凭据**；凭据只由后端在运行时读取。
- 你的批次与记录落在 `data/state.sqlite3`，上传的 xlsx 落在 `data/uploads/`，导出文件在 `data/outputs/` 下按批次分目录；失败诊断产物在 `data/runtime/judge-diagnostics/`。**这些都不进版本库**（`data/` 已被忽略）。
- 界面上的**编号、标签、证据**都来自库里的原文；页面不推导业务标签。

## 4. 问题反馈

反馈请包含：**步骤号**（如 C7）、**批次 `run_id` / 记录键**（页面上的 `run_id` 与 `record_key`）、实际提示原文、与「应观察」的差异、以及必要的截图或页面保存（不要粘贴任何密钥）。

- **工程缺陷**（页面报错、计数不对、按钮无效、接口 5xx、文件下载失败）：属程序问题，请直接反馈给开发者修复。
- **业务口径分歧**（某个标签你认为不对、某条证据摘录不够、复核要求不合理）：属分类质量问题，**本阶段不作准确率结论**，请记录下来在 S07 一起处理——**模拟模式的标签是程序内合成逻辑，不是模型判断**。

## 5. 结束、恢复与文件保存

- **停止**：两个窗口各按 `Ctrl+C`。服务停止不影响已落库的批次；worker 停止时未消费的任务保持 `queued`，重新启动 worker 后会继续。
- **恢复**：把窗口 A／B 重新起起来即可；批次详情页的「立即刷新」会读到最新状态。**只需要看记录**时，可以不启动窗口 B。
- **本阶段不重跑**：B／C／D／E 组都是只读浏览，重复打开不会产生新批次；A／D 组各会**新建一个批次**（模拟跑，零费用），重复操作会多出批次，属正常。
- **需要保留的文件**：`data/state.sqlite3`（批次与记录）、`data/uploads/`（原始 xlsx）。导出与诊断产物不在本阶段验收范围（导出属 S05，已验收）。
- **不改动**你的 `config.toml`／`config.local.toml`：本阶段不新增任何配置键。
