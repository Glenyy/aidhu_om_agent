## 3. 记录边界（不代填）

- 本文件只记录用户明确表述的结论；**未逐条代填**指南 §2 的结果表，指南结果表保持原样。
- **B 组（中断与恢复）与 C 组（重启持久化与深链）的逐步数值未由用户逐条报告**。「这两组也通过」是接受这一结论的推论，**不是用户的逐条陈述**；其实现行为另有自动化证据（[r01 自动化审阅](../../automated/S04/r01-自动化审阅.md) §2.2 的真实 uvicorn 冒烟记录：`running` → 真实 `kill -9` → 新 worker 启动恢复标 `interrupted`／`unknown_after_interrupt 1` → 恢复后 `completed`，阶段一尝试总数恒等于记录数）。
- **本次验收不构成分类准确率结论。** 用户真实文件的 100 条批次走的是**模拟模式**（§2.2），且分类质量按 [plan/01 §4](../../../../../plan/01-需求与验收标准.md) 须用未参与调试的独立保留集在 S07 评估。
- **提示词 `1.2` 的改进效果未经真实验证**：S04 定为全程零真实调用，S03 遗留「记录 4 失败族」是否因此改善**未有证据**；该失败族按用户 2026-10-06 决定仍属后续处理。
- 未报告问题 ≠ 已证明无问题；若后续发现 S04 范围内的工程缺陷，按规则在已批准范围内修复、复审并更新指南。
