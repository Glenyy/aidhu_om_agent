## 2. 审阅步骤

### 步骤 1：生成 6 个合成样例

```bat
python -c "import sys; sys.path.insert(0, 'tests'); from pathlib import Path; from fixtures import excel_samples as s; out = Path('outputs/s02_samples'); out.mkdir(parents=True, exist_ok=True); print(s.normal_workbook(out/'normal.xlsx')); print(s.partial_failure_workbook(out/'partial_failure.xlsx')); print(s.missing_column_workbook(out/'missing_column.xlsx')); print(s.duplicated_id_workbook(out/'duplicated_id.xlsx')); print(s.multi_sheet_workbook(out/'multi_sheet.xlsx')); print(s.empty_refs_workbook(out/'empty_refs.xlsx'))"
```

应观察：退出码 0，依次打印 6 个路径（`outputs\s02_samples\normal.xlsx` … `empty_refs.xlsx`）；`dir outputs\s02_samples` 列出同样 6 个 .xlsx。样例是运行时合成的，仓库里不含二进制 Excel。

### 步骤 2：记录运行前的文件指纹

```bat
certutil -hashfile outputs\s02_samples\normal.xlsx SHA256
certutil -hashfile outputs\s02_samples\partial_failure.xlsx SHA256
```

应观察（本次实跑值，请抄下自己机器上的值用于步骤 10 对比）：

| 文件 | 运行前 SHA256 |
| --- | --- |
| normal.xlsx | `498df2a1caed9ba866a8d623c573f5ee795cef8ed76e8da9e6318c8894b94f11` |
| partial_failure.xlsx | `cdb8444eec7f5cd3e56e122f3237896b1af19e72378abcbf911dbf9232f6be8f` |

### 步骤 3：解析正常样例

```bat
python -m aidhu_om_agent inspect outputs\s02_samples\normal.xlsx --preview 3
echo 退出码=%errorlevel%
```

应观察（逐字实跑结果）：

```json
"status": "passed",
"sheet_name": "QA_REF",
"counts": { "total": 3, "valid": 3, "input_invalid": 0, "skipped_blank_rows": 1 },
"blockers": [],
"row_errors": [],
"warnings": [],
```

退出码 **0**。核对 `total = valid + input_invalid`（3 = 3 + 0）；末尾那 1 个全空行只进 `skipped_blank_rows`，不算记录。

### 步骤 4：核对编号、q/a、十个 ref 与来源行

同一条命令的输出里，`records_preview` 应逐字为：

| record_id | source_row | order_index | q | a | 有值的 ref |
| --- | --- | --- | --- | --- | --- |
| `"1"` | 2 | 0 | 问题一 | 回答一 | ref1 = `资料一` |
| `"2"` | 3 | 1 | 问题二 | 回答二 | 无（ref1—ref10 全为 `null`） |
| `"A-003"` | 4 | 2 | 问题三 | 回答三 | ref1 = `资料三第一行\n资料三第二行` |

核对要点：

- `source_row` 是 Excel 1-based 行号，表头为第 1 行，故首条数据是 2。
- 每条记录的 `refs` 固定含 `ref1`—`ref10` 共 10 项，缺失为 `null`，顺序不变。
- 第 3 条的 ref1 是**两行文本**，在 JSON 里显示为 `\n`（换行已统一为 LF）。
- 编号按原文保留：`"1"` 与 `"A-003"` 都没有被重新编号。
- `records_preview_note` 会说明只展示前 N 条。

### 步骤 5：显式指定工作表

```bat
python -m aidhu_om_agent inspect outputs\s02_samples\normal.xlsx --sheet QA_REF
```

应观察：`sheet_name` 仍为 `QA_REF`，其余与步骤 3 一致，退出码 0。

再试一个不存在的表名：

```bat
python -m aidhu_om_agent inspect outputs\s02_samples\normal.xlsx --sheet 不存在的表
echo 退出码=%errorlevel%
```

应观察：退出码 **1**，`status` 为 `blocked`，blocker 码 `SHEET_AMBIGUOUS`，消息为「工作簿中没有工作表 '不存在的表'；实际工作表：QA_REF」。

### 步骤 6：部分失败样例（关键步骤）

```bat
python -m aidhu_om_agent inspect outputs\s02_samples\partial_failure.xlsx
```

应观察（逐字实跑结果）：

```
status = passed
counts = {'total': 4, 'valid': 1, 'input_invalid': 3, 'skipped_blank_rows': 2}
row_errors:
  来源行 3  编号 None  编号：缺失或为空
  来源行 4  编号 "3"   q：缺失或为空
  来源行 5  编号 "4"   a：缺失或为空
```

退出码 **0**。核对：

- `1 + 3 = 4`，恒等式成立；2 个空行（全空行 + 仅空白行）另计。
- 失败行**没有**被填造内容：缺少 q 的那条 `q` 为 `null`，缺少 a 的那条 `a` 为 `null`；失败行仍保留编号和来源行，便于回查。
- 这是「部分失败」，不阻断整个批次，退出码仍是 0。

### 步骤 7：批次级阻断三项

```bat
python -m aidhu_om_agent inspect outputs\s02_samples\missing_column.xlsx
echo 退出码=%errorlevel%
python -m aidhu_om_agent inspect outputs\s02_samples\duplicated_id.xlsx
echo 退出码=%errorlevel%
python -m aidhu_om_agent inspect outputs\s02_samples\multi_sheet.xlsx
echo 退出码=%errorlevel%
```

应观察（逐字实跑结果，三条退出码都应为 **1**）：

| 样例 | blocker 码 | 消息要点 | counts |
| --- | --- | --- | --- |
| missing_column | `MISSING_COLUMNS` | 第 1 行缺少必要列：ref10 | 四项全为 `null` |
| duplicated_id | `DUPLICATE_RECORD_ID` | 编号必须唯一，发现重复编号：1（来源行 2, 4） | `total=3, valid=3`（已扫描完） |
| multi_sheet | `SHEET_AMBIGUOUS` | 没有 QA_REF，且有 2 个可见工作表，无法自动确定；可见工作表：Sheet1、Another | 四项全为 `null` |

核对要点：`status` 均为 `blocked`，且 `records_total` 均为 **0**——批次级问题存在时**不产出任何可处理记录**，必须先修正输入。缺列与多表是在扫描数据行之前就中断的，所以 `counts` 为 `null` 而不是 0，这不是错误。

### 步骤 8：空 ref 仍是有效记录

```bat
python -m aidhu_om_agent inspect outputs\s02_samples\empty_refs.xlsx
```

应观察：退出码 **0**，`status=passed`，`counts={total:1, valid:1, input_invalid:0, skipped_blank_rows:0}`，`row_errors` 为空。

核对要点：ref1—ref10 全空**不是输入失败**。「资料不足」属于后续阶段的业务判断（S03），本阶段只判断输入是否完整。

### 步骤 9：单测全量

```bat
python -m pytest -q
```

应观察：退出码 0，`139 passed`。其中 S01 原有的 `tests/unit/backend/test_config.py` 22 项仍在（本阶段未引入回归）。

### 步骤 10：确认原 Excel 未被改写

```bat
certutil -hashfile outputs\s02_samples\normal.xlsx SHA256
certutil -hashfile outputs\s02_samples\partial_failure.xlsx SHA256
```

应观察：两行 SHA256 与步骤 2 记录的值**完全一致**。另外用 Excel 打开 `normal.xlsx`，应看到只有原始的 13 列，没有新增「判断」「标签」「状态」等列，多行资料内容没有被截断或改写。

### 步骤 11（可选）：错误输入的表现

```bat
python -m aidhu_om_agent inspect outputs\s02_samples\没有这个文件.xlsx
echo 退出码=%errorlevel%
```

应观察：退出码 **2**，提示 `读取错误：找不到输入文件：outputs\s02_samples\没有这个文件.xlsx`。退出码 2 表示**调用方式有误**，与预检结论（0 = 通过、1 = 阻断）区分开。
