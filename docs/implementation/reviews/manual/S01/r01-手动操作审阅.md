- 第 13 步的 `pnpm dev` 用 `Ctrl+C` 停止；它只监听本机 5173，不影响其他程序。
- 本阶段没有 run/resume 业务命令，也没有需要保留的批次数据；重复执行上述步骤不会产生累积业务状态。
- 第 5、6 步创建的 `configs\config.toml` 已按第 6、7 步删除，属预期。若你希望保留本机配置，可自行复制 `config.example.toml` 为 `config.toml` 或 `config.local.toml`（后者已在 `.gitignore` 中）；**不要**把真实密钥写进 `config.toml`，密钥只放 `.env`。
