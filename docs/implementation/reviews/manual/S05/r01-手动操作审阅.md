## 1. 准备与启动

### 1.1 启动界面服务（窗口 A）

打开 Anaconda Prompt：

```bat
conda activate aidhu_agent
cd /d D:\pyProjects\dha_projects\aidhu_om_agent
python -m aidhu_om_agent serve
```

应观察：

```
INFO:     Application startup complete.
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
界面地址：http://127.0.0.1:8000/（按 Ctrl+C 停止）
```

**保持窗口 A 开着**。若 8000 被占用，改用 `python -m aidhu_om_agent serve --port 8124`，后文端口随之替换。

`python -V` 若不是 `Python 3.12.15`，把上面的 `python` 换成 `D:\anaconda\envs\aidhu_agent\python.exe`。

### 1.2 启动队列消费者（窗口 B）

**再开一个** Anaconda Prompt：

```bat
conda activate aidhu_agent
cd /d D:\pyProjects\dha_projects\aidhu_om_agent
python -m aidhu_om_agent worker
```

应观察：

```
worker w-<12 位标识> 已启动（模式 mock）；数据库 <项目根>\data\state.sqlite3
按 Ctrl+C 停止；退出时保留未消费的 queued 任务。
```

- **默认就是模拟模式**（`--mode mock`），不调用真实模型、零费用。**不要**加 `--mode real`。
- 窗口 B 大多数时候是**安静**的，只在真的消费到任务时才有输出。
- 同一时刻**只允许一个 worker**；再开一个会立刻退出（见 §5.1）。
- 本指南 C 组会**两次重启**窗口 B（一次带环境变量、一次不带），E 组会**故意停掉再拉起**——都是设计好的步骤。

### 1.3 打开页面并强制刷新

浏览器访问 **http://127.0.0.1:8000/** ，按一次 **`Ctrl+F5`**。

**本轮前端有改动，必须强刷**。判定方法：按 `F12` → Network，页面加载的脚本名应为 **`assets/index-A7CRyeKF.js`**（S04 是 `index-zZESsEwi.js`）；样式为 **`assets/index-DkcV_sId.css`**。

`dist/frontend` 已是本次重建的产物；若页面 404，在**另一个**终端执行 `pnpm install` 后 `pnpm build`。静态文件按请求读盘，重建后**不需要重启服务**。

## 4. 结束、恢复与文件保存

- **停止**：窗口 B `Ctrl+C` 停 worker；窗口 A `Ctrl+C` 停服务。停 worker 后已入队但未消费的任务**原样留在队列**，下次启动 worker 会继续；**导出任务也一样**。
- **中断了想接着做**：重新起服务与 worker 即可，数据都在 `data\state.sqlite3`。详情页的「立即刷新」与「刷新导出」按钮可随时手动刷新。
- **想重来一遍**：不必删库——在 `/` 页再点一次「开始判别（整批）」会**新建批次**。
- **需要保留的文件**：`data\state.sqlite3`、`data\uploads\`、**`outputs\`（本轮新增，两份导出文件都在这里）**、以及你另存/截图/抄下的编号与计数。C7 步骤建的那个 `blocked-outputs` 文件**请删掉**，别留在项目根。
- **是否产生费用**：全程模拟模式，**零真实调用、零费用**。
