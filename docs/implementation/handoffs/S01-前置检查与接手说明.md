### 9.1 Node 结论更正

原文结论：“2026-10-06 核验的 Vue 官方快速开始要求 Node 22.x 至少 22.18.0……默认 22.16.0 不满足该脚手架入口要求。”

| 包 | 实测 engines | Node 22.16.0 |
| --- | --- | --- |
| vite 7.3.6 / 8.3.3 | `^20.19.0 \|\| >=22.12.0` | 满足 |
| @vitejs/plugin-vue 6.0.9 | `^20.19.0 \|\| >=22.12.0` | 满足 |
| pnpm 12.9.1 | `>=18` | 满足 |
| vue / element-plus / vue-tsc / typescript | 无 Node engines 限制 | 满足 |

本项目按 S01 决定**手写最小 Vue 文件、不使用 `create-vue`**，因此 **无需安装新 Node，也无需使用 Codex 缓存中的 Node 24.19.0**。原文关于“S01-01 必须提出独立安装兼容 Node 或显式使用已验证运行时”的要求已不适用；S01-01 只需确认默认 Node 22.16.0 为唯一前端运行时并安装 pnpm。
