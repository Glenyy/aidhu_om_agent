## 1. 阶段目标与边界

用未参与调试的保留集评估分类质量，并完成必要工程回归，形成有真实证据的首版验收报告。

不得在验收中悄悄修改提示词、模型配置或评分规则。若依据保留集结果调试，该集合转为回归数据，新的质量验收须补充未用于调试的数据。1000 条工程验证使用模拟客户端，不据此宣称真实模型吞吐或准确率。

## 3. 阶段完成条件

非正确误判正确比例 ≤5%，Macro-F1 ≥0.80，验收集有效记录完成率 100%；编号无遗漏重复、标签合法，工程检查通过。需复核记录仍按原预测计分。

步骤开发完成后自动执行以下审阅，保存 reviews/automated/S08/r01-自动化审阅.md。命令必须在实际开发时验证后填写；不能把尚未安装工具或未实现测试标为通过。

- 检查冻结版本及真实服务标识、核定和划分摘要、各类至少 5 条；确认保留集未参与调试。
- 计算总体一致率、各类精确率/召回率、Macro-F1、混淆矩阵、复核比例；5% 指标分母为人工核定两种非正确标签的数量。
- 核对所有有效编号、状态、标签和分子分母，不通过删掉失败记录提高成绩；技术失败解决后重新生成完整报告。
- 执行与冻结版本相关的工程回归，1000 条模拟检查顺序/编号/计数/恢复/导出；报告实际耗时和已知未知用量，不推算未经验证成本。
- 若未通过，记录真实结论并停止交付验收推进；需要调试时更新数据归属和开发前方案，再准备新的保留集。

自动化审阅发现问题，在已批准范围内修复并复审；扩大范围前更新具体方案。报告通过后状态为“待手动审阅”，不代替用户接受。

## 4. 阶段结束需生成的手动操作审阅文档

自动化审阅通过后，根据真实实现生成 reviews/manual/S08/r01-手动操作审阅.md，写入版本、环境、准备数据、完整命令/点击、逐步预期和反馈记录。该阶段指南至少覆盖：

1. 核对报告中的代码、规则、模型配置与冻结清单及实际批次版本。
2. 抽查原始问题、答案、refs 和 agent 原预测，确认复核后的人工标签未被当成 agent 成绩。
3. 核对三类样本数量、混淆矩阵总数、5% 分母及有效完成率；检查编号无缺失重复。
4. 查看中断恢复、独占 worker、导出和 1000 条模拟验证证据，对业务质量与工程结果分别给出验收意见。

指南展示真实报告路径和实际计数。已有工程证据充分时不要求重复付费模型调用；人工接受不能被自动检查通过代替。
