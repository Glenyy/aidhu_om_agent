## 1. 阶段目标与边界

建立人工核定基准、固定校准/保留集划分和可验证评估工具，仅用校准集调整规则并冻结待验收版本。

正式业务 Excel 不需要判断列。带人工标签的数据只用于评估，原有初标可参考但由人工确认或纠正。不得由模型自造标准答案；本阶段不使用保留集模型结果调试，不实现日常人工复核结果回读。

## 3. 阶段完成条件

人工核定和划分清单可审阅；指标用已知矩阵验证；冻结版本可重现。校准成绩不代替保留集验收。

步骤开发完成后自动执行以下审阅，保存 reviews/automated/S07/r01-自动化审阅.md。命令必须在实际开发时验证后填写；不能把尚未安装工具或未实现测试标为通过。

- 检查编号唯一、标签合法、人工核定来源、排除原因和数据摘要；初标与人工核定不混作模型成绩。
- 检查固定划分可重复、无交叉、校准三类覆盖、保留每类至少 5 条；早期模型调试样本进入校准或回归，不进入未使用保留集。
- 用手算小矩阵验证总体一致率、Macro-F1、各类精确率/召回率、非正确误判正确比例及零分母展示。
- 检查评分始终使用 agent 原预测；复核标记不删除样本，人工修订不覆盖预测；缺失/重复/非法标签及技术失败明确报告。
- 检查校准记录与冻结清单；确认没有按保留集模型输出修改提示词或规则。

自动化审阅发现问题，在已批准范围内修复并复审；扩大范围前更新具体方案。报告通过后状态为“待手动审阅”，不代替用户接受。

## 4. 阶段结束需生成的手动操作审阅文档

自动化审阅通过后，根据真实实现生成 reviews/manual/S07/r01-手动操作审阅.md，写入版本、环境、准备数据、完整命令/点击、逐步预期和反馈记录。该阶段指南至少覆盖：

1. 对照样本编号检查人工核定标签、范围排除原因和争议处理记录。
2. 查看划分清单和每类数量，确认校准与保留不重叠，未满足数量时补充样本。
3. 按实际 evaluate 命令计算指定小矩阵，与指南给出的人工计算值核对。
4. 检查校准误判与原始 ref，审阅变更依据及冻结版本；确认保留集未被用于模型调试。

人工核定由用户负责，开发者提供记录和计算工具。指南明确人工工作与自动检查边界；未取得人工核定不能宣称质量已通过。
