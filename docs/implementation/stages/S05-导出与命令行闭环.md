## 1. 阶段目标与边界

实现四工作表 Excel、两阶段 JSONL 和命令行批处理，使输入、执行、恢复、导出形成可操作的闭环。

本阶段不开发网页，不计算正式分类成绩。evaluate 命令只确定参数合同与帮助说明，计算逻辑在 S07 实现；未实现时明确报错。CLI 通过共享服务排队，由唯一 worker 执行，不绕开队列自行消费。

## 3. 阶段完成条件

CLI 能提交和观察批次；导出完整且可追溯。文件失败不改变记录判断，每次导出生成独立文件，不覆盖输入或既有人工填写文件。

步骤开发完成后自动执行以下审阅，保存 reviews/automated/S05/r01-自动化审阅.md。命令必须在实际开发时验证后填写；不能把尚未安装工具或未实现测试标为通过。

- 用独立模拟数据核对四张工作表、JSONL、编号/顺序、成功失败复核数量、合法标签与空技术失败标签。
- 验证 ref10、空 ref、中文和长文本、文本编号与公式样式字符串保持原值；超出 Excel 单元格能力时不得静默截断，完整原文在明细中保留并明确提示。
- 注入第二份文件生成/发布失败，确认不公布半份产物；重跑导出不重复记录，不覆盖已修改文件。
- 验证 worker 执行时导出快照的一致性、CLI 等待/非等待及部分失败反馈；再次恢复不重做已保存模型阶段。

自动化审阅发现问题，在已批准范围内修复并复审；扩大范围前更新具体方案。报告通过后状态为“待手动审阅”，不代替用户接受。

## 4. 阶段结束需生成的手动操作审阅文档

自动化审阅通过后，根据真实实现生成 reviews/manual/S05/r01-手动操作审阅.md，写入版本、环境、准备数据、完整命令/点击、逐步预期和反馈记录。该阶段指南至少覆盖：

1. 按实际 CLI 命令执行独立模拟批次，打开四张工作表并对照 JSONL 编号、证据和计数。
2. 填写复核清单的人工判断和复核说明，另存文件；再次导出，确认旧文件及 agent 预测保留。
3. 受控中断后恢复，核对阶段一复用、尝试次数和失败记录业务标签为空。
4. 制造指南指定的导出失败，观察独立失败状态并重新导出，确认两份完整文件才可获得。

指南区分模拟数据与真实模型调用；使用实际 CLI 入口，不引用当前尚未实现的启动脚本。evaluate 的正式操作到 S07 补齐。
