## 1. 阶段目标与边界

形成可安装的 Python 包、可检查和构建的 Vue 骨架、有效配置入口及真实依赖锁，后续模块能在独立环境实现。

本阶段不调用模型、不创建业务数据库、不实现上传/判别页面。骨架页面只验证工具链，不表示产品流程已完成。
