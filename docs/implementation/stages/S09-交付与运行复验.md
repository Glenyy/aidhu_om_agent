## 1. 阶段目标与边界

交付 Windows 本地源码、锁定依赖、静态前端、配置模板和可复现运行指南；用户可以独立完成一次运行及恢复。

本阶段不扩展云部署、多用户权限、在线标注或检索功能。不因打包重复调整已验收规则；规则/模型变化须记录版本并重新验证。交付包不包含凭据和真实业务运行数据。

## 3. 阶段完成条件

用户按最终指南可安装、启动、运行、下载并恢复任务；脚本只控制所属进程，凭据不入库，交付版本与验收记录一致。

步骤开发完成后自动执行以下审阅，保存 reviews/automated/S09/r01-自动化审阅.md。命令必须在实际开发时验证后填写；不能把尚未安装工具或未实现测试标为通过。

- 在独立环境从锁定依赖安装并验证包导入、资源读取、前端构建和静态访问；必要工程回归通过。
- 验证启动/停止/再启动、重复启动、端口占用及 worker 独占；不得结束非本项目进程或删除数据库/人工填写文件。
- 使用 Start-Process 启动后台服务时指定 -WindowStyle Hidden；检查密钥不进入日志、配置快照、报告或交付包。
- 核对指南所有命令、入口、文件路径、结果字段与实际实现；区分模拟复验和真实服务兼容/质量报告。
- 核对交付清单、锁定依赖、代码/规则版本、验收报告、备份恢复说明及未解决事项。

自动化审阅发现问题，在已批准范围内修复并复审；扩大范围前更新具体方案。报告通过后状态为“待手动审阅”，不代替用户接受。

## 4. 阶段结束需生成的手动操作审阅文档

自动化审阅通过后，根据真实实现生成 reviews/manual/S09/r01-手动操作审阅.md，写入版本、环境、准备数据、完整命令/点击、逐步预期和反馈记录。该阶段指南至少覆盖：

1. 在指南指定的独立 Windows 环境按完整命令安装依赖、复制配置并设置环境变量。
2. 使用实际脚本启动本地网页，上传无敏感样例，查看进度并下载四工作表 Excel 和 JSONL。
3. 关闭浏览器后重新访问；受控停止/重启并恢复，核对已保存阶段复用和编号数量。
4. 填写复核清单并另存，验证重新导出保留旧文件；查看失败原因、日志和普通恢复/显式重试操作。
5. 核对交付与验收版本，记录用户最终意见；未反馈项保持待用户操作。

指南明确哪些步骤模拟调用，哪些需要用户已批准的少量真实调用。所有脚本和命令必须实际验证，不能沿用骨架占位命令。
