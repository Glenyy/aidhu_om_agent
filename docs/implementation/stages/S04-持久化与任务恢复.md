## 3. 阶段完成条件

已保存检查点可复用，未知调用占旧预算；普通恢复/显式续开/仅收尾区分；无重复消费、半份标签或失步统计。

步骤开发完成后自动执行以下审阅，保存 reviews/automated/S04/r01-自动化审阅.md。命令必须在实际开发时验证后填写；不能把尚未安装工具或未实现测试标为通过。

- 外键/唯一/CHECK、短事务、API 类读写与 worker 并发、结构版本和迁移回滚。
- 捕获占位后中断、阶段一提交后继续、阶段二已完成跳过、finalize_only 零新增请求。
- 重开计划中断再次恢复不重复续开，SDK/执行器/worker 不叠加预算。
- 双 worker 拒绝、系统性模型故障暂停、队列保留、自动导出排队不虚报成功。

自动化审阅发现问题，在已批准范围内修复并复审；扩大范围前更新具体方案。报告通过后状态为“待手动审阅”，不代替用户接受。

## 4. 阶段结束需生成的手动操作审阅文档

自动化审阅通过后，根据真实实现生成 reviews/manual/S04/r01-手动操作审阅.md，写入版本、环境、准备数据、完整命令/点击、逐步预期和反馈记录。该阶段指南至少覆盖：

1. 用独立模拟批次和实际验证入口查看 SQLite 快照、记录状态及调用次数。
2. 在指南指定的位置受控停止并恢复，核对阶段一复用及最终编号数量。
3. 检查普通恢复与显式重试差异，尝试第二个 worker，观察明确拒绝。
4. 模拟全部记录完成但未收尾的恢复，确认只补终态/导出请求，不调用模型。

指南必须提供可复现的故障注入与只读数据库查看方法，使用独立测试数据；此时导出文件尚未实现，不能让用户下载空产物。
