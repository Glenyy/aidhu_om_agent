## 1. 阶段目标与边界

本地浏览器完成上传 Excel、启动批次、查看进度与记录、发起恢复、下载导出文件；关闭页面不影响 worker。骨架与单条界面已在 S03 交付，本阶段是把它们补成完整闭环。

采用 Vue 3、TypeScript、Vite、Element Plus 与 FastAPI；本阶段不加入在线人工改标签、复核回读或评估页面。启动/停止脚本到 S09 完成，此时提供经过验证的直接启动命令。

## 3. 阶段完成条件

用户通过浏览器完成批处理闭环，API 不承担模型长任务；进度、最终判断、处理失败及需复核记录展示清楚。

步骤开发完成后自动执行以下审阅，保存 reviews/automated/S06/r01-自动化审阅.md。命令必须在实际开发时验证后填写；不能把尚未安装工具或未实现测试标为通过。

- 核对上传、创建、恢复、分页筛选、导出及下载合同与 OpenAPI；模拟合法/非法状态、幂等冲突和文件归属错误。
- 执行前端类型检查与构建，接口类型和状态枚举保持一致；API/worker 两进程并发时事务与队列正确。
- 端到端验证上传→批次→进度→证据→导出→下载；刷新/关闭浏览器后 worker 继续，重复请求不创建重复任务。
- 验证部分失败、全输入失败、暂定判断与复核标记、技术失败无标签，以及静态页面深链接和 API 错误不被页面兜底吞掉。

自动化审阅发现问题，在已批准范围内修复并复审；扩大范围前更新具体方案。报告通过后状态为“待手动审阅”，不代替用户接受。

## 4. 阶段结束需生成的手动操作审阅文档

自动化审阅通过后，根据真实实现生成 reviews/manual/S06/r01-手动操作审阅.md，写入版本、环境、准备数据、完整命令/点击、逐步预期和反馈记录。该阶段指南至少覆盖：

1. 按指南启动实际 API、worker 和前端，上传指定含中文编号与 ref10 的独立样例。
2. 查看进度，刷新或关闭页面后重开，确认批次继续；重复提交测试不生成重复处理。
3. 筛选复核和失败记录，打开证据详情核对原始 q/a/ref 与标签说明。
4. 发起导出、查看任务状态和文件历史，下载完整 Excel/JSONL；按指南处理输入错误及中断恢复。

指南写出实际页面名称、按钮与完整启动命令，并分别说明开发模式和静态构建模式；此阶段不要求用户使用未实现的 start-local.ps1。
