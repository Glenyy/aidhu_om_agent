## 2026-10-06 S03 返工：真实文件技术失败的可观测性与提示词合规（第十三次）

**根因（全部由实测证据支撑，非推测）**：

| 项 | 事实 | 证据 |
| --- | --- | --- |
| 失败形态 | `partial_failed`、`label: null`、`failure = {stage: stage2, code: OUTPUT_INVALID, attempt_count: 3}`；阶段一 5,563 ms + 阶段二 78,390 / 83,219 / 99,047 ms ≈ **4 分 26 秒** | `data/runtime/job_probe2.json` |
| 触发来源 | 该文件记录 `1` 的 **ref6** 非空（项目自带样例的 ref6 长度均为 0），失败消息为「证据摘录不是 ref6 原文的真实子串」 | `data/runtime/ref6_probe.json`、`ref6_scan_all.json` |
| 数据特征 | ref6 是公众号整段粘贴：**723 字符 / 132 行**、**38 个 `**`**、**21 行整行只有两个空格**、1 个 U+00A0；该文件 100 个 (记录, ref) 组合中 **36 个**含 ≥10 个 `**` 或 ≥5 行纯空白行 | `data/runtime/ref_probe_counts.json`、`ref6_visible.txt` |
| **不是真实模式故障** | 真实模式在合成样例上 **3 条记录全部一次成功**（标签分别 未检索到正确资料 / 回答正确 / 检索到正确资料但回答错误） | `data/runtime/s03-06/pipeline-20261006-150056.json` |
| 校验规则 | `quote not in normalize_text(source)`，仅容忍 CRLF→LF 与首尾空白 | [agent/validation.py:101-104](../src/aidhu_om_agent/agent/validation.py#L101-L104) |
| 耗时构成 | = 3 次尝试 × 阶段二单次延迟；**校验失败不退避**，所以时间被放大 3 倍 | 同上；R1 单次 64—99 s 是模型固有速度 |
